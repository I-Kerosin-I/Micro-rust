# Micro — симулятор микропрограммируемого процессора (Rust)

Переписанная на Rust версия учебного симулятора **Micro** (курс «ЭВМ и периферийные
устройства», лабораторные работы №4 и №6). Оригинал: C#/WPF (`D:\Projects\Micro`),
совместимость по форматам файлов — с Delphi-версией «Micro classic».

- Ядро симуляции: `micro-core` (без GUI, покрыто тестами).
- Интерфейс: `micro-app` (egui/eframe, тёмная/светлая темы, без WebView).

## Сборка и запуск

```bash
cargo run --release -p micro-app     # запуск
cargo test                           # тесты (46 юнит + интеграционные на файлах ЛР)
cargo clippy                         # линтер
```

Release-бинарник: `target/release/micro(.exe)` (~6,3 МБ).

## Возможности

- Исполнение микропрограмм: Рестарт / Шаг / Команда / Пуск-Стоп (F5/F8/F9/Ctrl+R),
  регулятор скорости (10 … 1 000 000 МК/с), трасса с экспортом в CSV.
- Редакторы: микропрограммная память (64×19 + комментарии, контекстные меню-справочники),
  ОЗУ (байты/слова + ASCII, клавиатурный HEX-ввод независимо от раскладки), регистры,
  таблица дешифрации кода операции (0/1/X).
- Форматы файлов оригинала: `.MEM`, `.XMEM`, `.RAM`, `.RG`, `.TTA` — побайтовая совместимость.
- Схема процессора с живыми значениями регистров, подсветка изменений, тосты,
  предупреждение о несохранённых изменениях при выходе.
